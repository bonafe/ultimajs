Referência da DSL de template

Todo o vocabulário reativo do ComponenteReativo, num só lugar. Qualquer caminho usado em data-se, data-senao-se ou como valor de data-classe aceita um ! na frente pra negar (ex: data-se="!carregando").

AtributoOndeSintaxeEfeito
data-mapaqualquer elemento{"atributo":"caminho"}Binding de atributo/propriedade nos dois sentidos
data-classequalquer elemento{"classe":"caminho.booleano"}Liga/desliga classes CSS
data-estiloqualquer elemento{"propriedade-css":"caminho"}Define propriedades de estilo inline
data-refqualquer elemento"nome"Expõe o elemento em this.refs.nome
data-se<template>"caminho"Início de uma cadeia condicional
data-senao-se<template>"caminho"Continuação da cadeia condicional
data-senao<template>(sem valor)Fallback incondicional
data-lista<template>"item in caminho [: chave]"Repete o conteúdo por item de um array

data-mapa

Binding de atributo ou propriedade, nos dois sentidos. No sentido dado → DOM, o valor lido no caminho é aplicado seguindo uma ordem de casos especiais — textContent, checked (para checkboxes), value, campos datetime-local — antes de cair no genérico setAttribute. 

<input data-mapa='{"value":"nome"}'>
<input type="checkbox" data-mapa='{"checked":"ativo"}'>
<span data-mapa='{"textContent":"nome"}'></span>

No sentido DOM → dados, qualquer elemento com data-mapa escuta o evento nativo change e escreve o valor lido de volta no caminho correspondente — é assim que um <input> vira binding bidirecional, sem sintaxe extra.

A mesma sintaxe compõe componentes reativos aninhados: data-mapa='{"data-dados":"caminho"}' num <componente-filho> repassa um objeto inteiro pra dentro dele, nos dois sentidos.

data-classe

<div data-classe='{"destaque":"ativo", "erro":"!valido"}'></div>

Liga ou desliga cada classe via classList.toggle, conforme o valor (booleano, ou negado com !) do caminho correspondente.

data-estilo

<div data-estilo='{"border-color":"corDoStatus"}'></div>

Define uma propriedade de estilo inline a partir do valor do caminho. Se o valor for undefined/null, a propriedade é removida.

data-ref

<input data-ref="campoBusca">

// depois de renderizar:
this.refs.campoBusca.focus();

Expõe o elemento em this.refs.nome. Se mais de um elemento usar o mesmo nome (comum dentro de uma lista), this.refs.nome vira um array.

Condicionais — data-se / data-senao-se / data-senao

<template data-se="carregando">
  <p>Carregando...</p>
</template>
<template data-senao-se="erro">
  <p>Algo deu errado.</p>
</template>
<template data-senao>
  <p>Tudo certo.</p>
</template>

Uma cadeia é uma sequência de <template> irmãos consecutivos, começando por data-se, com zero ou mais data-senao-se, terminando opcionalmente num único data-senao. O primeiro caminho verdadeiro vence.

Se o ramo vencedor for o mesmo da renderização anterior, o conteúdo não é destruído e recriado — só reprocessado no lugar. Isso importa de verdade quando há um data-lista com chave dentro do ramo: a identidade dos itens sobrevive a renderizações em que a condição não mudou.

Listas — data-lista

<template data-lista="tarefa in tarefas : id">
  <li data-mapa='{"textContent":"tarefa.titulo"}'></li>
</template>

Sintaxe: "item in caminho"; opcionalmente "item, indice in caminho" (expõe também o índice); e um sufixo " : campo" que declara a chave de identidade dos itens.

Com chave utilizável — explícita, ou inferida quando todo item tem uuid ou id — a lista faz reconciliação por chave: os nós DOM de um item cuja chave continua presente são reaproveitados e só movidos de posição, não recriados. Sem chave (ou com chave ausente/repetida numa passada), a lista inteira é reconstruída a cada renderização.
