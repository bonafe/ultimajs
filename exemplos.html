Exemplos

Dois exemplos reais do repositório — um formulário pequeno que exercita toda a DSL de uma vez, e a aplicação completa que o projeto usa como campo de prova desde o início.

Formulário com componentes aninhados

Em src/html/componentes/z.exemplo/: um componente br-teste com todos os tipos de binding — texto, checkbox, cadeia condicional de três ramos, e uma lista de endereços reconciliada por chave, onde cada item é ele mesmo outro componente reativo (br-endereco) recebendo dados via data-mapa.

br-teste.html (recorte) 
<template data-se="exibir_endereco">
  <div id="enderecos">
    <template data-lista="endereco, indice in enderecos : cep">
      <br-endereco data-mapa='{"data-dados":"endereco"}'></br-endereco>
    </template>
  </div>
</template>

Espaço — a aplicação de referência

O Ultima começou em 2020 como um protótipo de visualização em treemap, e o "Espaço" continua sendo a aplicação que valida o framework na prática: um ambiente onde você adiciona elementos — vídeos, imagens, iframes, grafos, painéis de dados — e os organiza numa de duas visualizações alternáveis, com todo o estado persistido no navegador via IndexedDB. Sem backend.

O Espaço em execução: três elementos (toque, vídeo, grafo do próprio banco local) organizados automaticamente pelo layout de treemap.

A segunda visualização organiza os mesmos elementos em janelas flutuantes, arrastáveis e redimensionáveis — trocar entre as duas é uma ação do menu, sem perder dados.

O Espaço não é só uma demo — é onde bugs reais do framework aparecem primeiro. A página Sobre tem mais contexto sobre a origem do projeto.
