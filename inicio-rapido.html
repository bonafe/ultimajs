Início rápido

Não existe pacote no npm nem CDN oficial ainda — o Ultima se usa incluindo os arquivos-fonte diretamente, como módulos ES nativos. É assim que o próprio projeto se usa internamente.

1. Pegue os arquivos do núcleo

Copie (ou clone o repositório e referencie) os dois arquivos que formam o núcleo do framework: 

src/html/componentes/componente_base.js
src/html/componentes/componente_reativo.js

Nenhum outro arquivo é obrigatório — o resto do repositório é a aplicação de referência ("Espaço") construída em cima desses dois.

2. Crie o template e a classe do componente

Todo componente tem dois arquivos: um .html (o template) e um .js (a classe, que estende ComponenteReativo quando precisa de binding de dados, ou ComponenteBase quando não precisa).

meu-contador.html 
<div>
  Total: <span data-mapa='{"textContent":"total"}'></span>
  <button id="incrementar">+1</button>
</div>
meu-contador.js 
import { ComponenteReativo } from './componente_reativo.js';

export class MeuContador extends ComponenteReativo {

    constructor() {
        super(
            { templateURL: './meu-contador.html', shadowDOM: true },
            import.meta.url
        );

        this.addEventListener('carregou_componente', (evento) => {
            // composedPath()[0], não evento.target — ver o Guia pra entender por quê
            if (evento.composedPath()[0] !== this) return;

            this.dados = { total: 0 };

            this.no_raiz.querySelector('#incrementar')
                .addEventListener('click', () => {
                    this.dados = { total: this.dados.total + 1 };
                });
        });
    }
}

customElements.define('meu-contador', MeuContador);

3. Use o componente

<script type="module" src="./meu-contador.js"></script>

<meu-contador></meu-contador>
Sem passo de build. Sirva os arquivos com qualquer servidor estático (python3 -m http.server, por exemplo) e abra no navegador. Os caminhos em templateURL são resolvidos relativos ao próprio arquivo .js do componente (via import.meta.url), não relativos à página — então componentes são independentes de onde são usados.
