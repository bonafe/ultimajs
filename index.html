Web Components reativos,
100% JavaScript nativo.

Ultima é um framework para construir componentes reutilizáveis usando só o que o navegador já sabe fazer — Custom Elements, Shadow DOM e módulos ES nativos. Sem build, sem npm install, sem dependências carregadas em runtime.

Começar agora Ver no GitHub
contador.html 
<div data-mapa='{"textContent":"total"}'></div>
<button onclick="this.getRootNode().host.incrementar()">+1</button>

<!-- sem build, sem framework rodando por baixo: é o navegador lendo o atributo -->

Por que Vanilla JS

A filosofia do projeto desde o início: código que roda nativamente no navegador é uma boa prática, não uma limitação.

01

Zero dependências

Nenhuma biblioteca é carregada de CDN em tempo de execução. O que roda é exatamente o arquivo .js que você importa — sem bundler, sem passo de build, sem node_modules.

02

Padrões da Web de verdade

Componentes são Custom Elements reais, com Shadow DOM opcional de verdade — não uma abstração por cima que parece Web Components. Interopera com qualquer outro código HTML/CSS/JS.

03

Reatividade declarativa

Binding de atributo, condicionais, listas com reconciliação por chave, propriedades computadas e observadores — direto em atributos data-* no seu HTML, sem sintaxe de template proprietária pra aprender.

A sintaxe

Um vislumbre do vocabulário completo — condicional, lista com chave e binding nos dois sentidos, tudo no mesmo componente.

lista-de-tarefas.html 
<input data-mapa='{"value":"novaTarefa"}'>

<template data-se="tarefas.length">
  <ul>
    <template data-lista="tarefa in tarefas : id">
      <li data-classe='{"feita":"tarefa.feita"}'>
        <input type="checkbox" data-mapa='{"checked":"tarefa.feita"}'>
        <span data-mapa='{"textContent":"tarefa.titulo"}'></span>
      </li>
    </template>
  </ul>
</template>
<template data-senao>
  <p>Nenhuma tarefa ainda.</p>
</template>
